# Вклад

Спасибо, что копаетесь. Проект маленький и честный, правки приветствуются.

## Что нужно знать перед правкой

1. **`worker.ps1` обязан быть в UTF-8 с BOM.** Windows PowerShell 5.1 без BOM
   читает файл как ANSI и молча ломает разбор кириллицы. CI это проверяет.
2. **Типы в PowerShell:** `[ushort]` не существует, нужно `[uint16]`.
   Метод нельзя назвать `Move` или `Wheel` — PowerShell 5.1 отказывается
   вызывать такие статические методы. Обойдено именами `MoveTo`/`ScrollWheel`.
3. **COM-объекты не кэшируются.** `AutomationElement` протухает при перерисовке
   дерева, и вместо успеха будет исключение. Кэшируются только идентификаторы,
   перед действием делается свежий поиск — см. `Resolve-Target`.
4. **Ловушки Windows задокументированы в README**, раздел «Ловушки, на которые
   уже наступили». Прежде чем «чинить» что-либо, сверьтесь с ним и с
   `THIRD_PARTY_NOTICES.md`.

## Проверка перед PR

```bash
npm run check     # синтаксис
npm test          # автопрогон, ожидается «ИТОГ: 39 ок, 0 провалов»
```

Автопрогон **не двигает курсор**: только чтение — скриншоты, окна, дерево UI,
OCR, буфер, CDP-чтение. Мышь и клавиатуру он не трогает намеренно.

## Чего не надо предлагать

- Зависимости, требующие внешних бинарных модулей (`.node`, `.dll`, Python,
  `uvx`). Нулевой бинарный состав — сознательная фича, а не случайность.
- Правку `ConvertTo-Json -Depth` в меньшую сторону. Узел дерева UI — это
  примерно два уровня вложенности, и слишком маленькая глубина молча
  подставляет строку вместо объекта.
